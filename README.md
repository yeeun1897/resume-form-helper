# 이력서·자기소개서 양식 도우미

지원하는 곳(대기업, 공공기관, 외국계, 스타트업, 디자인·마케팅, 연구·학계)과 언어, 경력에 맞춰
이력서·자기소개서 양식을 추천하고, 내용만 채우면 되는 Word(.docx) 파일이나 PDF로 만들어 주는 웹페이지예요.

- 로그인·데이터베이스·API 키 없이 동작해요.
- 입력한 내용은 브라우저 안에서만 처리돼요. 네트워크 통신은 보안 설정(CSP `connect-src 'none'`)으로 막아 두었어요.
- 빌드 과정 없는 정적 파일(`index.html`, `styles.css`, `app.js`, `docx.js`)이에요.

## 쓰는 법

`index.html`을 브라우저로 열면 돼요. 배포할 때도 이 폴더를 그대로 올리면 돼요. 빌드 명령은 필요 없어요.

양식 안의 이름·연락처는 모두 가짜 예시(`홍길동`, `010-0000-0000`, `name@example.com` 등)예요.
